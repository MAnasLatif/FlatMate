# Changelog

Notable changes to FlatMate are recorded here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the project will use [Semantic Versioning](https://semver.org/) once it has releases.

## [Unreleased]

### Added

- Repository structure, contributor documentation, CI workflow, and issue and pull request templates.
- Software Requirements Specification and architecture overview.
- Mobile app foundation: Expo SDK 58 with Expo Router, HeroUI Native, the Supabase client with encrypted session storage, linting, type checks and unit tests.
- App icon, Android adaptive icon and splash screen.
- Supabase backend initialized, with a database test that every public table has row-level security, and database types generated for the app.
